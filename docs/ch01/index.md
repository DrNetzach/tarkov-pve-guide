# 第一章：受苦警告

## 序章

在你决定踏入塔科夫的世界之前，你需要知道一件事：这不是一款会对你微笑的游戏。

塔科夫是一款由俄罗斯工作室Battlestate Games开发的游戏。它的制作人叫尼基塔·布亚诺夫。记住这个名字，因为你以后会在各种场合用各种语气念出这个名字——愤怒的、绝望的、崩溃的、无语的。你骂他的次数会比你击杀敌人的次数还多。

尼基塔是一个很有意思的人。他会做游戏，但不会做人。九年测试期间，玩家吐槽服务器炸了，他在社交媒体上爆粗口回怼。Steam上架时一个游戏卖两遍，老玩家要重新买一份，差评如潮他还觉得委屈。优化做得一塌糊涂，8G内存的电脑卡成PPT他觉得是你的问题。AI穿墙打你，他觉得这是"硬核"。每次更新必出BUG，每次修BUG必引入新BUG，然后告诉你"这是Beta测试"——测了九年。

有人说尼基塔小时候一定经历了很多，才能做出这么折磨人的游戏。这话有道理。一个正常人的童年是不会让他长大后设计出"踩地雷断腿然后被AI补枪"这种东西的。尼基塔的童年大概是在西伯利亚的冰天雪地里，赤脚踩着地雷，被一群Scav追着跑，背着50公斤的背包找撤离点——然后撤离点是假的。只有这样才能解释他为什么觉得玩家应该经历同样的事情。

坦白说，塔科夫的问题是真实的：服务器会炸，AI会穿墙，优化感人，尼基塔的嘴比Scav的枪还毒。九年测试、差评如潮、Steam上架骚操作——这些烂事社区里的每一个人都经历过。本手册不会帮你回避它们。

但这里有一个塔科夫社区的共识：**你可以一边骂尼基塔，一边继续玩。** 你可以在论坛上用最"优美"的词汇问候他的家人，然后转身打开游戏再来一局。你可以在B站评论区打出三千字的控诉，然后发现自己已经玩了2000小时。这不是精神分裂，这是塔科夫玩家的日常。骂尼基塔和玩塔科夫从来不矛盾——事实上，骂他本身就是游戏体验的一部分。你骂得越狠，说明你爱得越深。

你可以同时承认"这个游戏有很多问题"和"这个游戏值得玩"。你可以同时觉得"尼基塔该骂"和"塔科夫独一无二"。这两件事不矛盾。

全世界有无数射击游戏，但没有第二个塔科夫。这就是为什么它的Steam评价是"差评如潮"，但每天仍有无数玩家在线。因为骂完之后，你还是会打开它。你知道为什么——因为那个在绝境中挣扎求生、在一次次失败中变强的感觉，只有它能给你。

你即将踏上一段旅程。这段旅程会让你愤怒、让你沮丧、让你怀疑自己。但走过这条路的人会告诉你——这是一段值得走的路。

## 你会经历什么

你将在出生后30秒内死亡。你会在还没搞清楚自己在哪的时候听到一声枪响，然后屏幕变黑，弹出一个你完全看不懂的伤亡报告。你不知道是谁杀了你，不知道子弹从哪飞来，你只知道——你的装备没了。

你会在捡到好东西后死掉。塔科夫有一个不成文的定律：你身上越值钱，死得越快。你会花25分钟搜刮整个地图，背包塞满了战利品，然后在距离撤离点还有50米的地方被一颗不知道从哪飞来的子弹终结。你的鼠标可能会出现一些物理层面的位移。

你会被一个穿破烂夹克的老头爆头。那个拿着生锈莫辛的Scav AI（游戏中的AI敌人，详见第四章），会在你全副武装、身穿六级甲（最高等级的防弹护甲）的情况下，隔着150米一发子弹命中你的面门。你的六级甲、你的满改M4、你花了一个小时配的装备，全部送给了一把PM手枪。这是塔科夫教你的人生道理：众生平等。

你会在地雷上失去双腿。有些地图有雷区，没有提示、没有标识、没有围栏。你会在正常走路的时候听到"砰"的一声，然后你的腿就没了。第一次你会愤怒，第二次你会困惑，第三次你会开始背雷区的位置。第四次你还是会踩到。

你会花30分钟配装然后5分钟死亡。选枪、选弹药、选护甲、选头盔、选背包、选胸挂、选医疗用品——这个过程可能需要很长时间。然后你进游戏，走了50米，被一枪爆头，全部装备丢失。

你会在局内找到一把好枪但没有地方放。你会在AI身上发现一把满配武器，但你的背包已经满了。你会痛苦地放下一些东西来捡这把枪，然后发现你放下的东西其实更值钱。

你会因为不知道任务目标在哪而在地图上乱转。任务描述说"找到化学制品的藏匿点"。你翻遍每一个角落，花了一个小时也没找到。退出游戏查攻略后发现——它就在你路过三次的地方。

你会在完成任务目标后死在撤离的路上。你成功到达任务地点，成功完成目标，然后在撤离的路上被击杀。塔科夫的任务设计有一种特殊的美学：它让你看到希望，然后亲手把它夺走。

你会经历"塔科夫循环"：满怀希望进入游戏→死亡→愤怒→不甘心→再来一局→死亡→更愤怒→发誓不玩了→5分钟后重新开始配装。这个循环会持续数百个小时。

你会在退出游戏后仍然心有余悸。塔科夫有一种独特的沉浸感，让你在退出游戏后手心出汗、心跳加速。这不是疾病，这是塔科夫。

## 这些苦难会塑造你

听起来很绝望？但请听我说完。

塔科夫的每一次死亡都不是惩罚——它是试炼。

你第一次被Scav爆头，你会骂街。第十次，你会开始检查自己的站位。第五十次，你会在Scav开枪之前就发现他并击杀他。第一百次，你甚至不会注意到自己已经自然地完成了这些动作——因为你已经变了。

塔科夫教会你的东西：

- **耐心**：你学会了不急躁，不贪枪，等敌人先动
- **谨慎**：你学会了每走一步都观察周围，每开一扇门都先听声音
- **地图记忆**：你不需要看地图就知道自己在哪，下一步该往哪走
- **声音判断**：你通过脚步声的远近、材质、方向判断敌人的位置和装备
- **风险评估**：你学会了判断"这波打不打""这个包舔不舔""这条路走不走"

这些不是游戏技能——这是一种直觉。当你在塔科夫中磨练了数百小时后，你会发现你在其他FPS中也变强了。因为塔科夫教给你的不是"怎么开枪"，而是"怎么思考"。

每一次死亡都在打磨你。每一次失败都在锻造你。你不是在"受苦"——你是在"修行"。

## PVE：你选择的路

说了这么多苦难，你可能已经把退款页面打开了。但请等一下——你选择的是PVE模式。

PVE模式不仅仅是一个"没有外挂的PVP"。它是一种完全不同的游戏体验。

**你可以用自己的节奏探索这个世界。** 不用担心出生点被蹲、不用担心撤离点被堵、不用担心刚搜到好东西就被六档哥击杀。你可以慢慢地走、慢慢地看、慢慢地学。塔科夫的世界观是丰富的——每一张地图都有故事，每一个角落都有细节。PVE让你有机会去发现这些。

**你可以专注于任务和剧情，体验完整的故事。** 塔科夫1.0正式版拥有完整的主线剧情系统——从"塔科夫之旅"到"门票"，从一个什么都不懂的PMC到最终面临"救世主"或"堕入黑暗"的抉择。PVE模式让你可以完整地体验这条剧情线，而不用担心被人打断。

**你可以从零开始，白手起家，建立自己的帝国。** 你的仓库从空空如也开始，你的藏身处从一堆废铁开始。通过一次次出图、一次次搜刮、一次次完成任务，你一点一点地积累——仓库从空到满，藏身处从废铁到工厂，装备从破烂到满配。这种从无到有的建造感，是塔科夫PVE最核心的乐趣。

**你可以体验一种独特的"苦难美学"。** 塔科夫是俄罗斯人做的游戏，它有一种俄罗斯特有的残酷诗意。它不追求"好玩"，它追求"真实"。它不给你廉价的多巴胺，它给你沉甸甸的成就感。你不会在塔科夫中感到"爽"——你会感到"值得"。这种美学在PVE模式中尤为明显：你的每一个成就都是自己挣来的，没有运气成分，没有别人施舍，只有你自己的汗水和成长。

**你最终会从一个什么都不懂的萌新，变成一个能独当一面的老登。** 这个过程可能需要几十个小时、几百个小时。但当你回头看的时候，你会发现——那些曾经让你崩溃的场景，现在已经是你的日常。那些曾经让你绝望的Boss，现在已经是你的提款机。那些曾经让你迷路的地图，现在你闭着眼睛都能跑。

这就是塔科夫的"成神之路"。

它不是一款"好玩"的游戏。它是一款有意义的游戏。你的每一次死亡都不是惩罚——它是试炼。你的每一次失败都不是终点——它是台阶。塔科夫在某种程度上是一款以宗教为底色的游戏——你从一个凡人开始，经历无尽的苦难，最终通过这些苦难获得超越。最好的结局叫"救世主"，最差的结局叫"堕入黑暗"。你走的每一步，都是在选择自己的命运。

PVE模式是你的修道院。在这里，你可以用自己的方式完成这段旅程。
