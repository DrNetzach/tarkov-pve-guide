# 第七章：AI的应对方式

## 7.1 AI分类概览

PVE模式中的AI敌人可以分为以下多类，每类的行为模式和应对策略各不相同：

| AI类型 | 出没地图 | 危险等级 | 简要说明 |
|--------|----------|----------|----------|
| 普通Scav | 所有地图 | 低 | 路人AI，装备差但数量多 |
| Rogues（叛变者） | 灯塔 | 中高 | 前USEC雇佣兵，装备精良，围绕据点活动 |
| Raiders（突袭者） | 实验室、储备站 | 高 | 精英AI，装备好枪法准 |
| Boss及随从 | 各地图特定位置 | 高 | 各地图Boss，各有特色机制（详见7.5节） |
| Partizan（游击队） | 海关、森林、灯塔、海岸线 | 高 | 独狼Boss，会放绊雷，伏击型 |
| The Goon Squad（三狗） | 海关、森林、海岸线、灯塔、破冰船（Knight） | 高 | 三人精英小队，协同作战 |
| Cultist Priest（邪教徒） | 海关、森林、海岸线、夜间工厂、中心区（仅21+级队列） | 高 | 夜间限定，潜伏伏击，毒匕首 |
| AI PMC | 所有地图 | 中高 | PVE模式下替代玩家的AI，行为模式模拟玩家 |
| Black Division Boss（黑狐） | 破冰船、终点站 | 高 | 黑色分队Boss，对激光有反应，双刷新点 |
| The Wedge | 破冰船 | 高 | 破冰船专属特殊Boss |

## 7.2 普通Scav

**行为模式**

- 装备较差，通常使用基础武器（莫辛、SKS、霰弹枪等）
- 数量多，分布广，是地图上最常见的AI
- 会在听到枪声后向声源方向移动
- 尸体对Scav有致命吸引力——附近刷新的Scav会跑过来"开饭"

**枪法特点**

- 枪法一般，但在近距离有一定威胁
- 偶尔会出现"神枪手"状态，一发爆头
- 远距离威胁较低

**应对策略**

- 不要掉以轻心，普通Scav偶尔也能一发爆头
- 击杀后尽快舔包离开，尸体会吸引更多Scav
- 使用消音器可以降低吸引附近Scav的概率
- 如果被多个Scav包围，优先找掩体逐个击杀，不要站在开阔地带

## 7.3 Rogues（叛变者）

**行为模式**

- 灯塔地图专属AI，由暴徒小队领导的前USEC雇佣兵
- 驻扎在山区木屋豪宅区域（1.1.5.0版本更新后的位置）
- 在山区木屋豪宅周边游荡，开放射界，索敌距离极远（约300m），会蹲草伏击
- 以Scav身份击杀不会扣业力

**枪法特点**

- 枪法精准，反应速度快
- 装备精良，通常使用中高端武器和护甲
- 会蹲草伏击、固定架枪，覆盖范围极广

**生命值数据**

| 部位 | 生命值 |
|------|--------|
| 头部 | 35 |
| 胸膛 | 180 |
| 胃部 | 130 |
| 双臂 | 105 |
| 双腿 | 110 |
| **总计** | **775** |

**应对策略**

- 不要正面强攻Rogues的据点，他们有固定架枪位置且索敌约300m，别在开阔地带露头
- 利用掩体peek射击，不要暴露在开阔地带
- 爆头仍然是击杀Rogues的最高效方式（头部仅35生命值）
- 以Scav身份击杀不会扣业力，可以放心攻击
- 建议携带中远距离武器，在安全距离外逐个击杀

## 7.4 Raiders（突袭者）

**行为模式**

- 实验室和储备站的精英AI
- 装备精良，通常使用改装武器和高等级护甲
- 会使用战术动作（掩体切换、包抄等）
- 会投掷闪光弹、手雷和烟雾弹

**枪法特点**

- 枪法精准，反应速度极快
- 射击节奏稳定，不会出现普通Scav的"神枪手"随机性
- 会在掩体后架枪，等待你暴露

**应对策略**

- 不要和Raiders对枪超过2秒——他们的反应速度比你快
- 利用掩体peek射击，打一枪换一个位置
- 注意Raiders投掷的手雷和闪光弹，听到投掷声立刻移动
- 在实验室中，Raiders密度极高，建议组队进入
- 储备站的Raiders通常在地下区域出现，注意楼梯和走廊

## 7.5 Boss及随从

塔科夫中每个地图都有独特的Boss，以下是各Boss的特点和应对策略：

**Reshala（海关）**

- 出没位置：宿舍楼或加油站附近
- 随从数量：4个小弟 + 本人 = 5人
- 特点：随从装备较好，但Reshala本人装备一般
- 应对：先击杀随从，再处理Reshala
- 详细数据请参考：<https://www.eftarkov.com/>

**Killa（立交桥）**

- 出没位置：商场内部
- 特点：反应极快、枪法极准，近战能力极强，身穿重甲。**Killa会主动冲锋追你**
- 应对：不要试图拉开距离——他会追过来。正确打法是**找拐角蹲着等他冲过来**，哪怕你用肉弹都有反应时间把他打死

**Shturman（森林）**

- 出没位置：锯木厂
- 特点：擅长远距离射击，随从也有远距离作战能力
- 应对：不要在开阔地带暴露，利用树木和建筑作为掩体

**Sanitar（海岸线）**

- 出没位置：**码头（Pier）、别墅区（Cottages）、海边警察局**；疗养院（东/西楼）已非固定刷点；概率游荡到气象站/水电站
- 随从特点：Sanitar和他小弟每个人手里都有包（医疗包）和针（注射器）
- 应对：使用80以上肉伤大口径武器一枪爆头秒杀

**Tagilla（工厂、立交桥、终点站）**

- 出没位置：厂房内部 / 立交桥
- 特点：身穿重甲、手持近战武器，近战极度危险
- 应对：保持距离，用枪解决。Tagilla的近战攻击伤害极高
- ⚠️ 夜间工厂的Tagilla刷率比白天更高
- ⚠️ 迷宫地图中的Tagilla是Shadow of Tagilla（暗影锤哥），是特殊变体，仅在迷宫出现。其他地图出现的都是普通锤哥

**Kaban（街区）**

- 出没位置：街区LexOs区域
- 随从数量：多（多种护卫类型，是塔科夫中护卫类型最丰富的Boss之一）
- 特点：围绕LexOs区域构建密集火力和多名护卫防线
- 应对：逐个击杀随从，不要同时面对多个敌人

**Kollontay（街区，俗称葛朗台）**

- 出没位置：塔科夫街区
- 刷新率：75%
- 护卫：科隆泰护卫（突击）、科隆泰护卫（安保）
- 特点：街区的第二个Boss，和Kaban同图。遇到时先判断是哪个Boss的区域再行动
- 应对：与Kaban类似，逐个击杀随从

**Glukhar（储备站）**

- 出没位置：火车站、黑象（Black Bishop）、停机坪附近、地下碉堡、黑马楼
- 随从：最多6人（侦察兵×2、突击兵×2、保镖×2），是塔科夫中人数最多的Boss队
- ⚠️ 活动期间会100%刷新在灯塔污水处理厂
- 随从特征：都穿毛衣。侦察兵用冲锋枪打肉弹、突击兵用AK系列+霰弹枪、保镖守在Glukhar身边
- 武器：ASH12 / M1A（M61/M993顶级穿甲弹），喊完话不到半秒就能融化你
- 护甲：一般穿4级弹挂甲，有时穿PACA，头戴3/4头
- 应对：胸口220头70，爆头效率远高于打胸口；随从会追杀到最后看到你的位置，保镖不会乱动
- ⚠️ 注意：游戏不定期举办活动，将Glukhar 100%刷新在灯塔污水处理厂

**Zryachiy（灯塔）** —— 俗称"小鹿"

- 出没位置：灯塔半岛Island区域，100%刷新
- 目前无保镖
- ⚠️ **机制杀警告**：小鹿的伤害是机制杀，和地图边界的狙击手一样，一旦触发即死。如果你已拥有灯塔小岛的进出许可（俗称"仙女棒"，红色棒体的信号发射器），**千万不要手贱去杀小鹿**，击杀后会永久失去进出许可
- 应对：擅长远距离射击，不要在开阔地带暴露；除非确定不需要再进岛，否则不要击杀

**Partizan（海关、森林、灯塔、海岸线）** —— 俗称"游击队"

- 出没位置：海关（20%）、森林（20%）、灯塔（20%）、海岸线（20%）
- 随从：无，独狼行动
- 特征：老游击队员，把塔科夫的森林和小路当作私人猎场。没有随从预警，没有固定领地可避
- **核心机制——绊雷**：Partizan会在路径上、搜刮点附近、路口处布置绊雷陷阱。战斗往往在你踩到绊雷的那一刻就开始了，此时你甚至还没看到他
- 行为模式：伏击、转移、只在自己选择的时机开火。是塔科夫中最不可预测的Boss之一
- 应对：走路时注意观察地面，尤其是明显路径上和搜刮点附近的绊雷；如果被不明方向射击，先移动再判断位置

**The Goon Squad（海关、森林、海岸线、灯塔）** —— 俗称"三狗"

- 三人组：Knight（骑士）/ Big Pipe（大管）/ Birdeye（鸟眼）
- 刷新地图：海关、森林、海岸线、灯塔（同一时间只在一张地图出现）；破冰船固定刷新 Knight（随行 2 名 Rogues）
- 刷新率：线上模式按网站数据；本地模式刷率随版本调整（约20-25%，以游戏内为准）
- Knight（骑士）：核心推进单位，主动拉近距离压迫玩家掩体，正面突破、中近距离高压推进
- Big Pipe（大管）：重火力单位，持续火力和榴弹压制，爆炸压制、远近切换、节奏破坏
- Birdeye（鸟眼）：远距离威胁，从侧翼或远处补枪，远程索敌、视野压制、狙击威胁
- 应对：三狗是一组协同作战的精英小队，先解决威胁最大的再处理其他；可使用三狗追踪工具（如 <https://takefu.cn/danye/sangou.html> ）确认当前刷新地图

**Cultist Priest（邪教徒祭司）** —— 夜间限定

- 出没地图：海关、森林、海岸线、夜间工厂、中心区（夜间限定，各图刷率约12-18%）
- 特征：只在夜间出现，带领邪教徒成员潜伏伏击
- 行为模式：潜伏在暗处，使用毒匕首近身攻击，极度安静
- ⚠️ **毒刀效果**：被邪教徒毒刀命中后会感染"未知毒素"，该状态撤离后**仍持续**，需局外治疗或用药解除。需要使用XTG-12解毒剂解除，其他多种药剂（如金星软膏）也带有解毒功能
- 应对：夜图中注意周围环境的异常动静，不要在可疑区域停留；携带夜视仪可以提前发现潜伏的邪教徒；务必携带解毒药品

**The Wedge（破冰船）** —— 破冰船专属

- 出没位置：破冰船，100%刷新
- 特征：破冰船地图的专属特殊Boss
- 应对：破冰船Boss密度极高（Knight+黑狐+Wedge同时存在），建议组队应对

**Black Division Boss（黑狐/黑色分队）** —— 破冰船、终点站

- 出没位置：破冰船（100% + 70%双刷新点）、终点站
- 特征：对激光有反应——武器上的激光指示器会触发黑狐的特殊行为
- 枪法特点：枪法精准，反应速度快，装备较好
- 行为模式：行为模式与其他AI不同，更加难以预测
- 应对：**不要使用激光指示器**；消音器可以降低吸引概率；夜图推荐四眼夜视仪 + IR镭射 + IR补光灯，避开光亮地带；利用掩体peek射击

## 7.6 AI PMC

**行为模式**

- PVE模式下替代玩家的AI，行为模式模拟真实玩家
- 装备随机，从基础到高端都有可能出现
- 会使用战术动作（掩体切换、包抄、投掷物等）
- 行为模式比普通Scav复杂，更接近真实玩家

**枪法特点**

- 枪法中等偏上，比普通Scav准但不如Raiders
- 会在掩体后架枪，等待你暴露
- 会使用投掷物

**应对策略**

- 不要轻视AI PMC，他们的行为模式比普通Scav复杂
- 利用掩体peek射击，不要在开阔地带对射
- 注意AI PMC的投掷物，听到投掷声立刻移动
- 近期版本中AI PMC强度有所提升，需要更加谨慎应对
- 击杀AI PMC可以获得较好的装备，值得冒险
- ⚠️ **AI PMC应优先处理**：AI PMC携带的弹药和护甲可能比Boss随从还猛，遇到时优先击杀
- ⚠️ **Boss小弟和AI PMC会丢雷**：他们的投雷非常精准，"就像追踪一样"。有时候存在bug导致你听不到拉保险的声音。听到投掷声（或看到雷）立刻跑

## 7.7 AI通用应对法则

以下是适用于所有AI类型的通用应对策略：

**手雷探AI / 逼走位**

- 向可疑区域丢手雷，AI会有**强制反应**（喊话+走位），可用来探出藏匿的AI、逼其离开掩体
- 注意：有概率卡AI不回应；AI对手雷的强制反应语音有约**30秒CD**

**战斗法则**

- **不要和AI对枪超过2秒**：AI的反应速度比你快，长时间暴露只会让你被击杀
- **利用掩体peek射击**：打一枪缩回来，再打一枪缩回来，不要站在开阔地带
- **爆头优先**：所有AI的头部生命值都最低，爆头是最高效的击杀方式
- **不要贪枪**：打中一两枪就缩回来，确认击杀后再探头

**声音与感知**

- **枪声会吸引AI**：消音器可以降低吸引概率，但不能完全消除
- **尸体会吸引Scav**：击杀后尽快舔包离开，不要在尸体附近逗留
- **手电对面向你的AI有反应**：如果AI正好面向你，手电会触发反应
- **激光部分AI有反应**：黑狐等特殊AI对激光有反应，注意配件选择
- **夜图开手电会增加AI锁敌距离**：夜图中谨慎使用手电

**战术技巧**

- **AI会"好奇"**：大口径武器着弹点、爆炸点会吸引AI去"调查"
- **利用AI的感知盲区**：AI的视野有范围限制，利用掩体和角度绕过其感知范围
- **不要在AI刷新点附近逗留**：AI会在特定位置刷新，注意远离这些区域
- **打完就走**：击杀AI后不要在原地逗留，枪声和尸体会吸引更多AI前来

**装备建议**

- **消音器**：强烈建议携带，可以大幅降低吸引AI的概率
- **瞄准镜**：中远距离交战时非常重要
- **夜视仪**：夜图必备，推荐四眼夜视仪
- **IR镭射/IR补光灯**：夜图中使用红外设备，不会触发AI反应且能辅助瞄准
- **耳机**：耳机是本体，没有耳机等于少了一半的感知能力

### 如何判断附近有没有威胁

在塔科夫中，判断威胁比击杀敌人更重要。以下是判断附近是否有AI的方法：

- **听脚步声**：脚步声的方向和材质可以告诉你AI的位置和距离。在木地板上走路和在金属上走路声音不同
- **听枪声类型**：霰弹枪声 = 近距离Scav；步枪声 = 可能有PMC或Boss；密集枪声 = Boss或Raiders区域
- **观察AI行为**：Scav会闲逛、说话、发出声音；PMC行为更aggressive，会主动推进和包抄
- **注意尸体**：尸体会吸引Scav前来"开饭"，如果你看到尸体附近有动静，说明有AI在靠近
- **听投掷声**：听到"叮"（拉保险）或"嘶"（手雷飞行）的声音立刻跑，Boss小弟和AI PMC的雷非常精准
