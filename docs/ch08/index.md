# 第八章：任务线总览

## 8.1 任务系统概述

塔科夫的任务系统是游戏的核心驱动力。完成任务可以：

- 提升商人信任度（解锁更高等级的商品和更好的装备）
- 获得经验值（快速升级以解锁跳蚤市场，Lv15）
- 解锁藏身处模块所需的特殊物品
- 推进主线剧情，走向不同结局

**萌新第一原则：有什么任务都去做。** 任务是你升级最快的方式，也是了解地图和游戏机制的最佳途径。不要挑任务——能接的全接，能做的全做，快速冲到Lv15解锁跳蚤市场才是前期最重要的目标。

**怎么接任务？** 在局外仓库界面，点击左侧商人列表中的某个商人，选择"任务"标签页，可以看到可接取的任务。点击"接受"即可。完成任务后回到同一商人处提交。

**注意**：塔科夫的任务没有任务追踪UI——不会在地图上标记目标位置。任务只有文字描述，你需要自己查攻略或记住目标位置。第一次做某个任务时，建议先在 eftarkov.com 上查清楚目标在哪，再进图。

## 8.2 3x4安全箱（Kappa容器）相关任务

3x4安全箱（俗称Kappa容器）是塔科夫中最大的安全箱，可以在局内保存物品不会因死亡丢失。

**获取条件（1.1.0.0更新后大幅简化）：**

- **等级要求**：40级
- **4个前置任务**：
    - Chemical Part 4
    - A Shooter Born In Heaven（天神射手）
    - The Tarkov Shooter Part 4（狙击疯魔）
    - Sew it Good Part 4（临行密密缝-4）
- 完成上述条件后解锁"Collector"（收藏家）任务线（⚠️ Collector的43个物品必须全部「战局内找到」（FiR），跳蚤/商人买的不能交任务）

**建议：** 前期先用默认的安全箱（2x2或根据版本不同有所差异），专注于升级和熟悉游戏。Kappa容器是后期目标，不要因为追求它而忽略了游戏体验。

## 8.3 商人解锁任务

部分商人需要完成特定任务才能解锁或升级信任度。以下是各商人的解锁和升级概况：

| 商人 | 解锁条件 | 信任度提升方式 |
|------|----------|----------------|
| 俄商（Prapor） | 初始可用 | 完成其任务 + 达到对应等级 + 消费金额达标 |
| 大妈（Therapist） | 初始可用 | 完成其任务 + 达到对应等级 + 消费金额达标 |
| 黑商（Fence） | 初始可用 | 通过业力（Karma）自动提升 |
| 滑雪商（Skier） | 需完成特定任务解锁 | 完成其任务 + 达到对应等级 + 消费金额达标 |
| 美商（Peacekeeper） | 需完成特定任务解锁 | 完成其任务 + 达到对应等级 + 消费金额达标 |
| 机哥（Mechanic） | 需完成特定任务解锁 | 完成其任务 + 达到对应等级 + 消费金额达标 |
| 服装商（Ragman） | 需完成特定任务解锁 | 完成其任务 + 达到对应等级 + 消费金额达标 |
| 耶格（Jaeger） | 需完成机哥（Mechanic）发布的"引荐"任务解锁 | 完成其任务 + 达到对应等级 + 消费金额达标 |
| 老登（Lightkeeper） | 推进主线（The Tour + Falling Skies + The Ticket 或 Batya） | 完成其任务线 |
| 裁判（Ref） | 竞技场相关 | 竞技场模式任务 |
| BTR司机 | 主线推进后自动出现 | BTR任务线 |

**注意：** 耶格（Jaeger）的解锁任务"引荐"（机哥Mechanic发布）是很多萌新卡住的地方。不要着急，按攻略来就能完成。老登（Lightkeeper）需推进主线（The Tour → Falling Skies → The Ticket 或 Batya）解锁，是后期目标。

## 8.4 支线任务概况

支线任务按商人分类，每类任务有其独特的风格和侧重点：

**俄商（Prapor）任务线**

- 特点：以战斗和军事任务为主，大量击杀类任务
- 地图：海关、储备站为主
- 奖励：武器、弹药、军事装备

**大妈（Therapist）任务线**

- 特点：以搜刮和存活为主，需要找到特定医疗物品
- 地图：各地图均有分布
- 奖励：医疗用品、食物、饮料、容器

**滑雪商（Skier）任务线**

- 特点：任务较为多样，有击杀、搜刮、放置等类型
- 地图：海关、立交桥为主
- 奖励：武器配件、护甲、弹药

**美商（Peacekeeper）任务线**

- 特点：以海岸线和实验室为主，后期任务难度较高
- 地图：海岸线、实验室为主
- 奖励：美元货币、西方武器、高端装备

**机哥（Mechanic）任务线**

- 特点：以武器改装和技术任务为主，需要提交特定武器配件
- 地图：各地图均有分布
- 奖励：武器配件、电子设备、藏身处材料

**服装商（Ragman）任务线**

- 特点：以护甲和服装任务为主，需要提交特定装备
- 地图：立交桥、街区为主
- 奖励：护甲、头盔、背包、胸挂

**耶格（Jaeger）任务线**

- 特点：以狩猎和生存为主，大量在特定条件下击杀的任务
- 地图：森林、灯塔为主
- 奖励：狩猎武器、食物、藏身处材料
- 注意：耶格的任务经常有奇葩条件限制（如"不穿护甲击杀""用霰弹枪在XX米外击杀"），是社区吐槽最多的任务线

**老登（Lightkeeper）任务线**

- 特点：后期任务线，需要先完成灯塔相关主线才能解锁
- 地图：灯塔为主
- 奖励：高端装备、特殊物品
- 注意：1.1.5.0版本后任务线已完全重做，更注重玩家游戏技巧的考验
