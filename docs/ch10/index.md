# 第十章：商人介绍

## 10.1 商人系统概述

塔科夫中的商人不仅是买卖装备的渠道，也是任务的主要来源。每个商人有：

- **信任度等级**（Lv1 → Lv4）：信任度越高，解锁的商品越多越好
- **货币类型**：不同商人接受不同的货币
- **专属商品**：部分装备只能从特定商人处购买

**信任度提升方式：** 需要同时满足三个条件——①完成该商人的任务 ②达到对应玩家等级 ③达到对应消费金额。三个条件缺一不可，光做任务不够，还要花钱买东西。信任度等级越高，能买到的装备越好。

## 10.2 全商人介绍

**俄商（Prapor）**

- 定位：军火商，主要出售苏俄系武器、弹药和军事装备
- 货币：卢布
- 信任度解锁内容：
    - Lv1：基础武器和弹药
    - Lv2：中端武器和配件
    - Lv3：高端武器和弹药
    - Lv4：顶级军事装备
- 特点：任务以战斗为主，是萌新最早接触的商人之一。俄商的武器性价比高，适合前期使用

**大妈（Therapist）**

- 定位：医疗商人，主要出售药品、食物、饮料和容器
- 货币：卢布/欧元
- 信任度解锁内容：
    - Lv1：基础医疗用品和食物
    - Lv2：更好的医疗用品和容器
    - Lv3：高端药品和大型容器
    - Lv4：顶级医疗物资
- 特点：**第一个满级的商人通常是大妈**，因为她的任务数量多且相对容易完成。医疗用品是每局必需品，大妈的重要性不言而喻

**黑商（Fence）**

- 定位：Scav 业力（Karma）商人，出售各种二手装备
- 货币：卢布
- 信任度提升：通过业力（Karma）系统自动提升。**不击杀其他Scav**是最基本的规则，击杀Scav Boss、帮助其他Scav等行为也会影响业力
- 特点：黑商的商品随机刷新，价格不固定。业力越高，Scav模式的装备质量越好、冷却时间越短。**不要在Scav模式击杀其他Scav或Scav Boss**，这会严重降低你的业力
- 黑车撤离：不喜欢玩Scav模式的话，坐黑车（付费撤离）慢慢攒业力也行

**滑雪商（Skier）**

- 定位：军火走私商，主要出售西方系武器、配件和护甲
- 货币：卢布/美元
- 信任度解锁内容：
    - Lv1：基础西方武器和配件
    - Lv2：中端武器配件和护甲
    - Lv3：高端配件和装备
    - Lv4：顶级改装件
- 特点：滑雪商的武器配件质量高，是改装枪械的重要来源

**美商（Peacekeeper）**

- 定位：联合国维和部队代表，主要出售西方高端武器和装备
- 货币：美元
- 信任度解锁内容：
    - Lv1：基础西方装备
    - Lv2：中端武器和弹药
    - Lv3：高端武器和装备
    - Lv4：顶级西方装备
- 特点：美商使用美元交易，前期需要攒美元。他的任务以海岸线和实验室为主，后期难度较高。美商出售的装备质量很高，是后期的主要装备来源

**机哥（Mechanic）**

- 定位：机械师，主要出售武器配件、电子设备和藏身处材料
- 货币：卢布/美元/欧元
- 信任度解锁内容：
    - Lv1：基础武器配件
    - Lv2：中端配件和电子设备
    - Lv3：高端改装件
    - Lv4：顶级配件和特殊物品
- 特点：机哥是改装枪械的核心商人，大部分高级配件只能从他这里购买。他的任务需要提交特定的武器配件和电子设备

**服装商（Ragman）**

- 定位：服装装备商，主要出售护甲、头盔、背包、胸挂和服装
- 货币：卢布
- 信任度解锁内容：
    - Lv1：基础护甲和背包
    - Lv2：中端装备
    - Lv3：高端护甲和头盔
    - Lv4：顶级防护装备
- 特点：服装商是购买防护装备的主要来源。他的任务需要提交特定的护甲和服装

**耶格（Jaeger）**

- 定位：猎人，主要出售狩猎武器、食物和藏身处材料
- 货币：卢布
- 解锁方式：需要完成机哥（Mechanic）发布的"引荐"任务才能解锁
- 信任度解锁内容：
    - Lv1：基础狩猎武器
    - Lv2：中端武器和食物
    - Lv3：高端狩猎装备
    - Lv4：顶级武器和特殊物品
- 特点：耶格的解锁任务是很多萌新卡住的地方。他的任务经常有奇葩条件限制（如"不穿护甲击杀""用霰弹枪在XX米外击杀""在负重状态下击杀"），是社区吐槽最多的任务线。但耶格出售的部分装备（如特定食物和藏身处材料）是其他商人没有的

**老登（Lightkeeper）**

- 定位：灯塔守望者，后期高端商人
- 货币：卢布
- 解锁条件：推进主线（The Tour + Falling Skies + The Ticket 或 Batya）
- 信任度解锁内容：
    - 解锁后即可购买高端装备
    - 完成其任务线可解锁更多特殊商品
- 特点：老登是解锁条件最苛刻的商人，需要投入大量时间完成各商人任务。1.1.5.0版本后其任务线已完全重做，更注重玩家游戏技巧的考验。老登出售的装备质量极高，是终局玩家的重要装备来源

**裁判（Ref）**

- 定位：竞技场商人
- 货币：竞技场货币
- 特点：裁判与竞技场模式关联，出售竞技场专属装备。如果你不玩竞技场模式，可以暂时忽略这个商人

**BTR司机**

- 定位：BTR装甲车驾驶员，提供局内服务和任务
- 货币：卢布
- 特点：BTR司机通过主线剧情自动出现。他的任务线与主线剧情紧密关联，其中"独立的代价"任务是救世主结局的必要条件。BTR装甲车会在灯塔、街区等地图中巡游，在局内找到BTR后可以使用以下服务：
    - **运送到特定地点**：搭BTR前往地图上的其他位置
    - **运送物品**：将物品交给BTR司机转移到其他地点
    - **火力掩护**：雇佣BTR提供火力支援
- 注意：BTR任务机制较繁琐——接任务、交任务、接下一个任务都需要单独开一局，而且BTR不是百分百刷新。80%的时间花在找BTR上
