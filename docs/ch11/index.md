# 第十一章：跳蚤市场未解锁前配装与防具推荐

## 11.1 配装思路

在Lv15解锁跳蚤市场之前，你的装备来源只有两条路：

**路线一：有老登——搞好关系让老登发装备**

如果你已经找到了愿意带你的老登，恭喜你，你的游戏体验会好很多。老登仓库里通常有大量闲置装备，搞好关系（多夸几句"牛逼"）之后，老登真的会恨不得把仓库给你。拿到装备后记得感恩，下次老登需要帮忙的时候主动站出来。

**路线二：萌新自强——从商人Lv1处购买**

如果没有老登，就只能靠自己。好消息是商人Lv1也能买到够用的装备，坏消息是你需要精打细算。以下是各商人Lv1可购买的推荐装备。

## 11.2 弹药核心原则

**穿透是弹药的生命线。**

塔科夫的伤害模型中，弹药的穿透值决定了你能否打穿敌人的护甲。穿透值越高，打穿护甲的概率越大。

- 穿透40+的弹药：理想标准，能打穿大部分4级以下护甲
- 穿透30-40的弹药：前期凑合用，遇到重甲就跑
- 穿透30以下的弹药：修脚专用，或者直接扔掉

**前期现实情况**：商人Lv1能买到的弹药穿透值普遍不高，30+就已经是能用的了。不要因为打不到40就不用——30+的弹药打Scav绰绰有余，先活下来再说。等解锁了更好的弹药再逐步升级。

前期弹药匮乏的时候，宁可用穿透高的弹药少打几发，也不要用穿透低的弹药扫一整匣。

**怎么查看穿透值？** 仓库中鼠标悬停在弹药上，可以看到穿透值等属性。也可以在 eftarkov.com 弹药页面查询所有弹药的详细数据。

## 11.3 武器推荐（商人Lv1可购）

**俄商（Prapor）Lv1**

- **AK-74U**：前期最常用的突击步枪，后坐力可控，弹药来源稳定。搭配PP弹（穿透值够用）是萌新的标配
- **PPSh（波波沙）**：高射速冲锋枪，可以换大弹鼓增加续航。适合近距离交战，工厂地图首选
- **SKS**：半自动步枪，单发伤害高，适合中远距离。前期性价比之王
- **莫辛纳甘**：栓动狙击枪，搭配LPS Gzh弹可以一枪爆头。适合远距离任务，但近战无力

**滑雪商（Skier）Lv1**

- **VPO-209卡宾枪**：.366 TKM口径，搭配FMJ弹经济实惠，适合点射秒杀。单发模式需要你打得准

**美商（Peacekeeper）Lv1**

- **MP5-k / MP5**：经典冲锋枪，上手简单，后坐力极低。推荐搭配9x19mm AP 6.3弹（穿透值较高）；如果买不到AP弹，PST GZH弹也能凑合用

**耶格（Jaeger）Lv1**

- **MP153**：半自动霰弹枪，搭配6.5鹿弹或食人鱼弹，近距离毁天灭地。适合工厂和室内地图

## 11.4 防具推荐

**护甲**

- **有老登**：让老登发，什么甲都比没有强
- **没有老登**：去服装商（Ragman）买。前期推荐3-4级护甲，能挡住普通Scav的子弹就够了
- **重要原则**：务必带头盔+面罩护住头部；PVE中AI爆头率高，头部防护优先——Scav一发爆头你就没了

**头盔**

- 前期不需要追求高端头盔，能挡一发子弹就行
- **必须带面罩**或者选择能安装面罩的头盔
- 没有面罩的头盔在PVE中作用有限——AI的爆头概率比你想象的高

**耳机**

- **耳机是本体**。没有耳机等于少了一半的感知能力
- 前期买最便宜的耳机就行，关键是戴了耳机能听到脚步声和枪声方向
- 不带耳机进图等于瞎子+聋子，存活率直接砍半
- **耳机之间有区别**：不同耳机的声音压缩范围、低音增强、环境音过滤等参数不同，效果差异明显。高端耳机能让你更早听到远处的脚步声。前期用便宜的就行，等熟悉游戏后可以研究耳机评测（B站有大量耳机对比视频）

**背包和胸挂**

- 前期买能装东西的就行，不要太纠结
- 胸挂优先选弹匣格多的，方便快速换弹
- 背包大小决定了你一趟能带多少战利品

**黑商（Fence）不推荐购买装备——价格死贵，性价比极低。** 黑商的商品是随机刷新的二手货，价格却比商人卖的还贵。除非你实在买不到某个东西，否则不要从黑商处购买装备。

## 11.5 配装示例

以下是几套前期配装方案供参考：

**穷鬼装（预算：3-5万卢布）**

- 武器：AK-74U + PP弹
- 护甲：3级甲（服装商购买）
- 头盔：基础头盔 + 面罩
- 耳机：最便宜的耳机
- 背包：基础背包
- 胸挂：基础弹匣挂
- 医疗：绷带 + 止痛药

**过渡装（预算：8-12万卢布）**

- 武器：MP5 + 绿色弹药 / SKS + 高穿弹
- 护甲：4级甲
- 头盔：带面罩的头盔
- 耳机：中档耳机
- 背包：中型背包
- 胸挂：弹匣格多的胸挂
- 医疗：急救包 + 止血带 + 止痛药

**小康装（预算：15-20万卢布）**

- 武器：AK-74U满改 / MP5满改 + 高穿弹
- 护甲：4-5级甲
- 头盔：带面罩的中高端头盔
- 耳机：高端耳机
- 背包：大型背包
- 胸挂：高端胸挂
- 医疗：完整医疗包组合

> 以上配装仅供参考，实际搭配请根据手头资源灵活调整。有老登发装备的话直接忽略以上内容。
