# 第十二章：藏身处升级物品汇总

## 12.1 藏身处概述

藏身处是塔科夫中的"基地"系统，你可以在这里：

- 制作物品和弹药
- 恢复生命值和体力
- 被动生产资源（如比特币、水、燃料等）
- 提升角色属性（如负重、搜索速度等）

藏身处的每个模块都需要升级，升级需要消耗大量材料和游戏币。前期材料紧缺，需要有选择性地升级。

## 12.2 升级优先级

**优先升级（前期必升）：**

1. **发电机（Generator）**：所有模块升级的前提，没有电力什么都做不了
2. **仓库（Stash）**：扩大仓库空间，解决前期"东西放不下"的问题。如果你买的是标准版，仓库升级是刚需；**EoD（Edge of Darkness，黑暗边缘版）玩家的仓库已是最大的一档，不需要急着升级**
3. **工作台（Workbench）**：解锁武器改装和弹药制作，前期最重要的功能模块
4. **医疗站（Medical Station）**：可以制作医疗用品，减少每局的医疗开支
5. **情报中心（Intelligence Center）**：缩短Scav冷却时间、解锁更多任务信息，是主线剧情推进的必要模块

**中期升级：**

6. **营养站（Nutrition Unit）**：制作食物和饮料，减少每局的补给开支
7. **水收集器（Water Collector）**：生产纯净水，是多个模块升级的前置条件
8. **太阳能板（Solar Power）**：减少发电机燃料消耗，长期来看节省大量卢布

**后期升级：**

9. **射击场（Shooting Range）**：测试武器性能，方便改枪
10. **健身房（Gym）**：提升体力和力量属性
11. **比特币矿场（Bitcoin Farm）**：详见12.3节

## 12.3 比特币矿场（Bitcoin Farm）

**⚠️ 萌新注意：比特币矿场是后期玩意，别前期想着搞。**

比特币矿场是藏身处中收益最高的被动生产模块，建成后可以持续产出比特币（可在跳蚤市场出售换取大量卢布）。但它的前置条件非常苛刻：

**前置条件：**

- 需要大量稀有材料（显卡、电路板等）
- 需要情报中心达到一定等级
- 需要持续供应电力（消耗燃料）

**升级需求：**

- 每一级需要更多的显卡（1级需要3张，2级需要8张，3级需要10张）
- 显卡是游戏中的高价物品，前期很难集齐

**收益：**

- 1级矿场（3张显卡）：每约14小时产出1枚比特币
- 2级矿场（8张显卡）：每约8小时产出1枚比特币
- 3级矿场（10张显卡）：每约5小时产出1枚比特币
- 比特币可以在跳蚤市场出售，价格随市场波动

> ⚠️ 以上显卡数量和产出时间可能随版本更新调整，以游戏内实际数据为准。

**萌新建议：**

- 前期不要追求比特币矿场，把资源投入到工作台、仓库等实用模块
- 等你解锁了跳蚤市场、有了稳定收入来源之后，再考虑攒材料建矿场
- 比特币矿场的回报周期很长，前期投入的材料价值远超收益

## 12.4 升级物品概况

藏身处升级需要的物品种类繁多，以下是各模块所需物品的大致分类：

| 模块 | 主要需要的物品类型 |
|------|-------------------|
| 发电机 | 燃料（金属燃料桶、夹板等） |
| 仓库 | 螺丝、铁钉、胶带、金属零件 |
| 工作台 | 电子元件、电路板、工具 |
| 医疗站 | 医疗物品（绷带、药品等） |
| 情报中心 | 电子设备、闪存盘、情报文件 |
| 营养站 | 食物、饮料、容器 |
| 水收集器 | 水过滤器、管件 |
| 比特币矿场 | 显卡、电路板、CPU |
