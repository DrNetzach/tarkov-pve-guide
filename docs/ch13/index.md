# 第十三章：萌新容易犯的错和常见老登坑害萌新手段

### 写在前面

在塔科夫的世界里，你最大的敌人不是AI，不是Boss，甚至不是服务器——而是你自己。以及那些看起来很友善的老登。

本章将分为两部分：第一部分是萌新自己容易犯的错，第二部分是老登们常用的"坑人手段"。请注意区分哪些是善意的玩笑，哪些是恶意的坑害。

## 13.1 萌新容易犯的错

**卖东西之前不查资料**

这是萌新最常犯的错误，也是损失最大的错误。你会在仓库里翻到一把奇形怪状的钥匙、一张看不懂的文件、一个不知道干嘛用的电子设备，然后觉得"这破玩意占地方"就卖给商人了。三天后你发现这东西在跳蚤市场上值几十万卢布，或者它是某个任务/藏身处升级的必需品。

**经典案例：**

- **邪教房钥匙**：看起来就是一把普通钥匙，实际上在跳蚤市场上价值不菲，因为它是进入邪教房（高价值搜刮区域）的必需品
- **各种情报文件**：看起来就是废纸，实际上是任务物品或者可以用来交易
- **显卡**：你以为是电子垃圾，实际上是比特币矿场的核心材料
- **LEDX**：你以为是医疗废物，实际上是高价物品

**原则：不清楚的物品，查一下资料再决定卖不卖。** 你可以在 eftarkov.com 上搜索任何物品的用途和价值。花10秒钟查一下，可能省下几十万卢布。

**不知道安全箱的用法**

安全箱（保险箱）是你仓库中最重要的容器。放在安全箱里的物品，即使你在局内死亡也不会丢失。萌新经常犯的错误是：

- 把任务物品放在背包里而不是安全箱里，死了之后丢失
- 不知道安全箱有大小限制，放了太多不值钱的东西占位置
- 不知道哪些东西应该优先放安全箱（高价值物品 > 任务物品 > 钥匙 > 弹药）

**不知道保险机制**

塔科夫的保险系统可以让你在死亡后有一定概率找回装备。但萌新经常不理解：

- 保险不是100%返还——如果敌人捡走了你的装备，保险不会赔付
- 保险有时间限制——你需要在一定时间内从商人处取回保险物品，否则就没了（具体时间取决于选择的保险商人，以游戏内为准）
- 不同商人的保险费率和返还概率不同
- **PVE模式下保险返还率比PVP高**——这是PVE的又一个优势

**不知道Scav冷却时间**

Scav模式（拾荒者模式）是PVE中重要的经济来源，但萌新经常不理解：

- Scav模式有冷却时间（具体时间随版本和黑商信誉变化），不能无限刷
- Scav的装备是随机的，有时候好有时候差
- Scav模式中不要击杀其他Scav，否则会降低黑商信誉
- Scav死亡不会影响你的主角色装备，放心大胆地用

**跳过任务对话**

塔科夫的一些任务对话包含重要信息，比如任务目标的位置、下一步该做什么。萌新经常手速太快跳过对话，然后在地图上乱转一个小时找不到目标。

**建议：第一次做某个任务时，不要跳过对话。** 如果你真的不想看，至少截图保存对话内容，之后可以慢慢看。

**不带医疗用品进图**

这是萌新最致命的错误之一。你可能觉得"反正会死，带医疗用品浪费钱"，但实际情况是：

- 一次擦伤就需要绷带，没有绷带就会持续流血
- 断腿需要止痛药+夹板，没有的话你走不动
- 大量失血需要止血带，没有的话你会在撤离路上死掉

**每局至少带：绷带 + 止痛药。** 这是最基本的医疗配置，花不了多少钱但能救命。

## 13.2 常见老登坑害萌新手段

在塔科夫的社交生态中，老登和萌新的关系是复杂的。大部分老登是善意的，但总有一些人以坑萌新为乐。以下是常见的坑人手段，请学会区分善意玩笑和恶意坑害。

**善意玩笑（不会造成实际损失）：**

- **闪光弹/闪光喷致盲**：老登可能会在安全区域对你扔闪光弹或者用闪光喷枪照你。这纯粹是逗你玩，不会造成实际伤害，顶多让你屏幕白几秒钟。笑一笑就过去了，下次记得离老登远一点。

**恶意坑害（会造成实际损失）：**

- **中心区保险箱旁的阔剑地雷**：这是最经典的坑人手段。中心区地图中有一个保险箱，老登会在保险箱旁边放置阔剑地雷（Claymore）。萌新兴冲冲地跑过去开保险箱，"砰"的一声就没了。**教训：任何搜刮点附近都要先观察有没有地雷或陷阱。**

- **告诉你去打小鹿（Zryachiy）**：老登会跟你说"灯塔小岛上有个Boss，杀了掉好东西"。如果你信了去打小鹿，你的仙女棒（灯塔小岛进出许可）就永久没了。**小鹿的伤害是机制杀，根本打不过；就算打过了，你也会失去进岛资格。** 这个坑的阴险之处在于：老登说的是"事实"（确实有Boss，确实掉东西），但隐瞒了关键后果。

- **让你去危险区域"练枪"**：老登会推荐你去某个地方"练枪"或"搜刮"，但那个地方实际上是Boss刷新点或者高危区域。你去了就是送装备。

- **故意给你错误的撤离点信息**：告诉你"这个撤离点是开放的"，但实际需要特定条件才能使用。你跑到撤离点发现用不了，时间又快到了，最后死在撤离点旁边。

- **推荐你用错误的弹药**：告诉你"这个弹药很好用"，但实际上穿透值很低，你拿着去打AI发现打不动。

- **让你先走他殿后**：表面上是照顾你，实际上是让你去探路踩雷。等你被AI打死了，他再去收割。

**如何避免被坑：**

1. **不要太信任陌生人**：即使是带你玩的老登，也要保持一定的警惕
2. **不确定的事情先查资料**：不要盲目听信别人的建议
3. **注意观察环境**：任何搜刮点附近都要先观察有没有陷阱
4. **学会说"不"**：如果老登让你去某个你不确定的地方，可以说"我不熟，你先走"
5. **记录坑你的人**：如果某个老登故意坑你，记住他的名字，下次不要再和他组队
